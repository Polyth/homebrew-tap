# Polyth Homebrew tap

```bash
brew install polyth/tap/polyth
brew services start polyth
```

`brew upgrade polyth` installs a newer release. `Formula/polyth.rb` is written by the
release workflow of [Polyth/Polyth](https://github.com/Polyth/Polyth) from each stable
release's server archives and their `SHA256SUMS-server.txt`; do not edit it by hand.
